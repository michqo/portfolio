# miqal.xyz — Portfolio

Source for my personal portfolio at **[miqal.xyz](https://miqal.xyz)**.

Built with Next.js 16 (App Router), TypeScript, Tailwind CSS v4, shadcn/ui, and next-intl for EN/SK localisation. Deployed on Vercel.

## Run locally

```bash
pnpm install
pnpm dev
```

Uses [**portless**](https://github.com/michqo/portless) — maps `miqal.localhost` to the dev server instead of the usual `localhost:3000`.
